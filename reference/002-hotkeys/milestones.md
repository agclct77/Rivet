# Rivet WPF 落地里程碑（逐步替代 Console）

## M1：WPF 殼建立與功能移植
- 建立 `Rivet.WPF` 專案，接線現有 Service/Infrastructure/DI。
- 手動啟動可完成：讀剪貼簿 → 翻譯（中↔英）→ 在 UI 顯示結果（暫可仍回寫剪貼簿，確保功能可用）。
- 基本日誌、錯誤提示正常；發行/建置腳本可產出 WPF 版本。

## M2：UI/UX 轉型（不回寫剪貼簿，改畫面呈現）
- 主視窗：單一「翻譯」按鈕，按下隱藏主窗。
- 譯文視窗：顯示結果、提供「複製」按鈕；預設不自動回寫剪貼簿。
- 熱鍵暫可手動啟動（尚未導入 RegisterHotKey）；驗證多筆翻譯可並行顯示多個譯文窗，互不干擾。

## M3：全域熱鍵與常駐化
- 加入 RegisterHotKey（固定 `Alt+.`），HwndSource Hook 收 `WM_HOTKEY`；註冊失敗記錄並退出。
- 系統匣/常駐：啟動後隱藏主窗，從托盤退出時解註冊熱鍵與釋放資源。
- 單實例：Mutex 防多開，後續實例喚醒既有窗或直接退出。

## M4：並行與剪貼簿策略強化
- 允許多譯文窗並行；剪貼簿預設不回寫，提供「複製」與可選/條件回寫（例如剪貼簿未變更時才覆寫）。
- 基本防重入/節流：避免熱鍵狂按導致過量請求（可限制同時翻譯數量或提示處理中）。
- 提示與通知：譯文完成可選 Toast/氣泡（非阻斷）。

## M5：設定與擴充（可選）
- 熱鍵設定化（改鍵）與合法性驗證。
- 權限提示：若目標程式為系統管理員，指引以同權限啟動。
- 文件與安裝體驗更新：使用說明、故障排除、啟動/開機自動啟動選項。
